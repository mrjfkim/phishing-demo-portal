Overview

GameDay Enhancer is a security testing tool designed to demonstrate how malicious browser extensions can request dangerous permissions. This extension is completely benign and used exclusively for product demonstrations and remote browser isolation (RBI) demonstrations.

When installed, this extension demonstrates the types of permissions that malicious extensions might request, including access to cookies, browsing history, and website content. Security teams can use this to test browser security policies and train employees on extension risks.

Features

  • Demonstrates malicious extension permission patterns
  • Safe and benign behavior - no actual data collection
  • Visual indicators when extension is active (orange border)
  • Educational alerts explaining extension risks
  • Perfect for product demonstration and RBI testing
  • Detailed permission explanations for awareness

Permissions

This extension requests the following permissions to demonstrate typical malicious extension behavior:

🌐
Read and change all your data on all websites
Demonstrates how malicious extensions can access website content, forms, and sensitive data.
🍪
Read and modify cookies
Shows how extensions can steal session tokens and authentication cookies.
📑
View your tabs and browsing activity
Demonstrates tracking capabilities - monitoring which websites you visit.
💾
Store data on your device
Shows how extensions can save collected data for exfiltration.
